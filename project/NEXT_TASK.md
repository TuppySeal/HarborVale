# Try the owned garage

Run Builds/HarborVale-GarageInventory/HarborVale.exe. Choose Drive Finch, stop near/inside PLAYER GARAGE, press G. Select an owned car to inspect it; Upgrade parts opens existing tabs. Buy another car opens the showroom (also H). Prepare receiver gearbox/brakes/tires, then drag a donor engine handle onto the receiver car and confirm labor. Drag to the right inventory area to remove an engine; drag stored engines back onto compatible cars. Select to drive equips a ready car. Empty chassis remain owned. Main menu Test Tempest/free lets you try the new Blender twin-turbo sports car without spending career money.
